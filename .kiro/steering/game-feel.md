# 游戏手感与反馈规则

- 每个关键动作至少给出两种反馈：视觉、音效、震动三选二；强平与高杠杆使用三种。
- 反馈必须说明状态，不只装饰：方向、杠杆、盈亏和危险程度应能一眼区分。
- 强度随风险或收益递增，并设置上限，避免持续抖动和音效堆叠。
- 优先顺序：输入响应 < 50ms、状态清晰、结算高潮、装饰细节。
- 一轮只改最多三个高价值手感问题；改后必须重新试玩完整核心循环。
- 尊重 `prefers-reduced-motion`；页面隐藏时停止持续音效和动画状态。
