# Requirements: 移动端控制与游戏手感

## Goal
在竖屏触屏设备上提供准确的蓄力交易与明确的风险反馈。

## Requirements
- [x] 开多/开空使用 Pointer Events 长按蓄力，松手成交，短按取消。
- [x] 输入处理覆盖 pointercancel、捕获丢失、页面隐藏和桌面键盘辅助。
- [x] 鼠标方差或经授权的陀螺仪生成手抖指数，并影响蓄力精度。
- [x] WebAudio 在用户手势后解锁；不可用时静默降级。
- [x] 开仓、结算、Buff 链、危险态与强平组合使用视觉、音效和振动反馈。

## Acceptance
移动端不触发默认缩放、选中或长按菜单。输入取消不会遗留仓位或蓄力状态。
