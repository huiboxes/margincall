# Requirements: 游戏界面与生涯复盘

## Goal
把构筑、读盘、交易和终局结果串成无说明即可游玩的屏幕流。

## Requirements
- [x] 标题页可选择主题并开始一局；对局可暂停且热切换主题。
- [x] Canvas 绘制主题化 K 线、持仓信息、风险线和行情演出。
- [x] 构筑商店显示卡牌效果、价格、锁定与刷新状态。
- [x] 行动界面显示权益、轮数、仓位、杠杆、倍率与 Bot 排名。
- [x] 终局提供权益曲线、名场面揭晓、风格画像、毒舌复盘、倍率回顾和分享长图。

## Acceptance
从标题页到终局的完整流程无死屏；在窄竖屏上交易控件保持可点击。
