# Requirements: 交易引擎与风险结算

## Goal
让玩家在 15 轮中完成仓位决策、逐 tick 结算、强平与监管事件。

## Requirements
- [x] 游戏状态覆盖构筑、行动、行情结算、轮间和终局，非法阶段操作无副作用。
- [x] 支持多空、杠杆、保证金、手续费、手动平仓、自动平仓和恐慌全平。
- [x] 支持裸奔、止损、双保险、只割不锁四种风险档位。
- [x] 强平、借贷、爆仓保护金和轮末结算保持会计一致。
- [x] 高倍率收益触发软性膨胀刹车与监管叙事事件。

## Acceptance
固定 seed 的自动对局能从开始走到终局，权益非负，终局后不能继续交易。
