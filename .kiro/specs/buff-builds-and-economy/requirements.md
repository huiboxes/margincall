# Requirements: Buff 构筑与经济

## Goal
提供有选择成本和成长路径的卡牌构筑，而非单纯猜涨跌。

## Requirements
- [x] 提供 32 张 Buff、四个流派、六个槽位、重复卡升级及 2/4/6 件套效果。
- [x] 每轮展示 3 张可选卡，支持购买、锁定、刷新与跳过。
- [x] 卡价、刷新费和跳过返还按权益计算；允许受限保证金借贷。
- [x] 倍率引擎以加法源和条件乘法源计算，并能展示贡献明细。
- [x] 情报类 Buff 能在不泄露完整剧本的条件下给出可操作提示。

## Acceptance
玩家可完成整局构筑；卡池不提供无效选择；每次收益结算可追溯到触发的 Buff 与套装。
