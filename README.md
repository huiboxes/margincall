# 《全仓以赴》（Margin Call）

> Balatro 式 buff 构筑 × 盲开历史行情 × 物理体感操作的 10 分钟一局金融肉鸽。
> 零依赖纯前端：**双击 `index.html` 即玩**（或任意静态服务器）。移动竖屏优先，桌面居中。

## 玩法 30 秒

1. **构筑与经济**：每轮 3 张 buff 卡**按身家定价**（白 1.5% / 蓝 3% / 紫 5% / 金 9% 权益）——前期每一块都肉疼，后期一张金卡就是一笔投资。拿 1 / 锁 1（锁价）/ 刷新（4% 权益起、每刷 ×1.6 几何递增；跳过返还 3% 权益；现金不够可保证金借贷，透支上限 25%）。6 槽位，同流派 2/4/6 件套，重复卡升级，据传有隐藏混合流派。
2. **收益倍率引擎**：盈利轮的收益经过倍率管线 (1+加法源)×(条件乘法源)。连胜🔥/雪球❄/耐心爆发⏳ 垫高基数；按情报操作、大波动轮、低杠杆持仓、与强平线擦肩……各自触发条件倍率。结算时**逐源点亮**：槽位发光、音阶上行、徽章滚动——构筑越强，数字越疯。点倍率徽章可看管线明细。
3. **读盘**：行情「盲开」——你不知道自己在玩哪段历史（局末揭晓名场面）。情报流 buff 会给方向/幅度/对手动向/幽灵线。
4. **行动**：**长按**开多/开空蓄力杠杆 1x→125x，松手成交；轻点取消；持仓时**双击**交易键 = 恐慌全平；或「本轮不动」（攒耐心层/钻石手蓄能）。
5. **结算**：逐 tick 演出，持仓时行情窗边缘随浮盈亏呼吸红绿辉光，逼近强平线红晕+警报；爆仓留 10% + 下轮免费刷紫卡；身家每翻 ×2/×3/×5/×10/×20 全屏里程碑庆祝；连续暴富/高杠杆/贫富差会触发监管电报（SEC 关注函 / 拔网线 / 反垄断）。
6. **15 轮强制平仓** → 生涯回放：权益曲线、人人有奖颁奖、风格画像（"87% 韭菜 + 13% 庄家"）、毒舌复盘、**倍率引擎复盘**、名场面揭晓 + 躺平对比、分享长图。

物理层：手抖指数（鼠标/陀螺仪方差）实时影响蓄力精度——重仓的人手真的会抖；移动端可授权陀螺仪。

## 与策划案的差异（M1 口径）

| 特性 | 策划案 | Demo |
|---|---|---|
| 行情 | 真实历史数据 | 程序生成剧本（10 个名场面参数化），局末揭晓"改编自哪段" |
| 刷新/买卡费 | 现金（meta） | v2：全部按身家定价（卡 1.5–9% 权益；刷新 4% 权益 ×1.6^次数；可借贷）——前期肉疼、后期追组合可能刷光也凑不齐 |
| 甩机清仓 | 陀螺仪甩动 | 降级：持仓时双击交易键 = 恐慌全平 |
| 手抖指数 | 陀螺仪 | 桌面鼠标方差 fallback；移动端可授权陀螺仪 |
| AI 解说 | LLM | 数据驱动模板（每套皮肤一套腔调） |
| 生涯回放 | 15s 视频 | 静态权益曲线 + 高光标注 + 分享长图（Canvas 导出） |
| 多人/赛季/大喊彩蛋 | M2/M3 | 不含 |

## QA

`../tools/qa.js`（Playwright 截图/自动对局）：

```bash
cd ../tools
node qa.js errors                 # 全主题切换零 console 报错
node qa.js title <theme>          # 标题页
node qa.js phase <theme> 42       # 对局各阶段
node qa.js auto <seed> <scen> <theme>   # 无人值守整局 + 结算页
node qa.js ov <theme>             # 监管电报 + 爆仓剧情 特写
node probe-seer.js <theme>        # 先知流 v4 探针：bend 改写行情 + 字印 chip + 整局冒烟
```

`?auto=1&seed=N&scen=luna` 可在浏览器里无人值守跑完整局（测试钩子）。
