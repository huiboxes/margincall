# MarginCall（《全仓以赴》）策划案

**一句话**：Balatro 式 buff 构筑 × 盲开历史行情 × 物理体感操作的 10 分钟一局金融肉鸽。竖屏移动端优先，零依赖纯前端，双击 `index.html` 即玩。

> 本文档描述**已实现**的游戏（v1.9 口径）。权威细节见 `README.md`；视觉主题开发见 `THEME-GUIDE.md`。
> 旧版"15 根 K 线 + 6 种 Buff"设计已废弃。

## 1. 核心循环（一局 15 轮）
1. **构筑**：每轮出 3 张 buff 卡，按身家定价。可拿 1、锁 1（锁价）、刷新或跳过。
2. **读盘**：行情盲开，玩家不知道在玩哪段历史。情报流 buff 提供方向、幅度、对手动向、幽灵线。
3. **行动**：长按开多/开空蓄力杠杆，松手成交。轻点取消。持仓时双击交易键为恐慌全平。也可选择「本轮不动」。
4. **结算**：逐 tick 演出。盈利轮收益经过倍率管线，按来源逐个点亮。
5. **监管**：连续暴富、高杠杆或贫富差触发监管事件（SEC 关注函 / 拔网线 / 反垄断）。
6. **终局**：15 轮后强制平仓，进入生涯回放。爆仓则留 10% 本金，下轮免费刷紫卡。

## 3. Buff 系统
- 32 张 buff，四大流派，6 个槽位。
- 同流派集齐 2/4/6 件触发套装。重复卡升级。存在隐藏混合流派。
- 收益倍率管线：`(1 + Σ加法源) × Π条件乘法源`。点倍率徽章可看明细。

## 4. 8 套界面风格
`neon`（主）、`sumi`、`crt`、`pop`、`vault`、`receipt`、`vapor`、`tarot`。
- 换风格 = CSS 变量/纹理 + 图表画法 + 音色预设 + 文案风味。
- 对局中可从暂停菜单热切换，不丢进度。
- 设计数值统一走 `css/tokens.css`。

## 5. 手感与反馈（核心卖点）
- 蓄力：杠杆逐档跳变，音高爬升，手抖指数（鼠标/陀螺仪方差）影响精度。
- 持仓：行情窗边缘随浮盈亏呼吸红绿辉光，逼近强平线红晕 + 警报。
- 结算：倍率来源逐个点亮，音阶上行。里程碑（×2/×3/×5/×10/×20）全屏庆祝。
- 终局：权益曲线回放、风格画像、毒舌复盘、倍率引擎复盘、名场面揭晓、分享长图。
- 反馈至少两种通道（视觉/音效/震动）。强平与高杠杆三种齐用。

## 6. 技术架构（现状）
- 经典 `<script defer>` + 全局命名空间 `window.MC`，**不是 ES Modules**。原因：保持 `file://` 双击可玩。
- 加载顺序固定：`core/*` → `ui/*` → `themes/*` → `main.js`。见 `index.html`。
- 模块职责：

| 文件 | 职责 |
|---|---|
| `js/core/util.js` | 事件总线、种子随机、格式化、存档 |
| `js/core/market.js` | 行情生成：10 个名场面剧本 × 轮内形态 |
| `js/core/buffs.js` | buff 定义、倍率引擎、套装、卡池定价 |
| `js/core/bots.js` | 5 个性格 bot，实时排名 |
| `js/core/tremor.js` | 手抖指数 |
| `js/core/audio.js` | WebAudio 合成，8 种音色预设 |
| `js/core/engine.js` | 15 轮状态机、经济、结算、监管 |
| `js/ui/chart.js` | 主题化 Canvas K 线 |
| `js/ui/theme.js` | 主题注册表 |
| `js/ui/app.js` | 屏幕流转、构筑商店、蓄力交互、演出、分享图 |
| `js/themes/*.js` | 8 套皮肤的 JS 侧 |

## 7. 已知技术债（当前 Spec：`.kiro/specs/split-modules-and-config`）
- 5 个 JS 文件超过 300 行：`app.js` 2003、`engine.js` 1446、`buffs.js` 516、`chart.js` 545、`audio.js` 328。
- 多个 CSS 文件超过 300 行（`base.css` 1318 等）。
- 玩法数值散落在 `engine.js` 顶部和 `buffs.js` 中，没有集中到 `config.js`。
- 约束由 `scripts/hooks/check-source.mjs` 用「棘轮」守住：超长文件只允许变短，不允许变长，新文件必须 < 300 行。

## 8. 不做
联网行情、账号、排行榜、多人、赛季、LLM 解说、视频生涯回放。

## 9. 验收
- 手机竖屏打开即玩，8 套风格可切换，一局 15 轮可完整打完。
- `node scripts/hooks/check-source.mjs` 通过。
- `?auto=1&seed=N` 无人值守整局跑完且控制台零报错。
